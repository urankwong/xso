用法

在 App「我的 → 局域网助手」开启服务，并确保手机与电脑连同一 WiFi。 浏览器打开本页后，把 App 显示的 4 位令牌填入右上角（若已开启令牌）。 各能力需在 App 内对应权限开关打开后才可用。

REST API

  • GET /api/status 服务状态与权限
  • GET /api/sources 源列表
  • POST /api/sources/import 导入 {raw,name?} 或 {urls:[]}
  • PATCH /api/sources/{id} {enabled:bool} 启停
  • DELETE /api/sources/{id} 删除源
  • GET /api/search?kw=&type=&page= 聚合搜索
  • POST /api/download {url,title,artist?,qualityLabel?} 入队下载
  • GET /api/downloads 下载任务列表
  • GET /api/logs 日志快照
  • GET /api/logs/stream 实时日志（SSE）

请求 /api/* 需带 ?token= 或 Authorization: Bearer <token>。
